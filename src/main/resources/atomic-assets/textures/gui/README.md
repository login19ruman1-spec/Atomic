Здесь лежат полноэкранные PNG-наложения вида изнутри противогаза:

- `gasmask_overlay.png` — основной визор; сборка помещает его в `assets/minecraft/textures/misc/pumpkinblur.png`.
- `gasmask_overlay_ash.png` — вариант с пеплом.
- `gasmask_overlay_cracked.png` — вариант с трещинами.

Для совместимости с обычным ванильным клиентом противогаз использует слот carved pumpkin: Minecraft сам показывает встроенный HUD-слой pumpkinblur. Это не требует клиентского мода. Ванильный сервер не может переключать разные HUD PNG индивидуально для каждого игрока; сейчас в качестве активного слоя используется основной overlay.
