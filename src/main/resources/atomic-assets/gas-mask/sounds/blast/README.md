Звуковые слои ядерного взрыва. Файлы должны быть в формате OGG Vorbis:

- `distant.ogg` — звук дальнего раската (загруженный файл `15ada...`), слышен на расстоянии 2000–3000 блоков.
- `wave.ogg` — звук ударной волны (загруженный файл `215596...`), слышен на расстоянии 50–2000 блоков.
- `close.ogg` — звук самого взрыва (загруженный `atomic-bomb-nuclear-explosion.ogg`), слышен в радиусе 50 блоков.

Путь: `src/main/resources/atomic-assets/gas-mask/sounds/blast/`.
Воспроизведение идёт на позиции каждого слушателя в категории MASTER: звук не зависит от стен, зданий и нахождения под землёй.
