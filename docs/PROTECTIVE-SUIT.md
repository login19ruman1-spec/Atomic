# Защитный костюм

Комплект работает только если надеты все четыре отмеченные плагином детали одновременно:
шлем, нагрудник, штаны и ботинки. Обычная кожаная броня того же цвета не считается комплектом.

## Рецепты

В верстаке 3×3:

**Шлем**
```
Кожа | Жёлтый краситель | Кожа
Кожа | Пусто           | Кожа
Пусто | Пусто          | Пусто
```

**Нагрудник**
```
Кожа  | Пусто           | Кожа
Кожа  | Жёлтый краситель | Кожа
Кожа  | Пусто           | Кожа
```

**Штаны**
```
Кожа  | Жёлтый краситель | Кожа
Кожа  | Пусто            | Кожа
Кожа  | Пусто            | Кожа
```

**Ботинки**
```
Пусто | Пусто | Пусто
Кожа  | Пусто | Кожа
Кожа  | Пусто | Кожа
```

Надень все четыре части в соответствующие слоты брони. Полный комплект снижает поступление радиации и частично защищает от кислотного дождя. В пределах 50 блоков от эпицентра защита костюма полностью подавляется.

## Противогаз и фильтр

Противогаз надевается отдельно в слот шлема, поэтому он заменяет шлем защитного костюма. Для полной защиты от радиационной пыли нужен фильтр. Фильтр устанавливается ПКМ по нему, когда противогаз надет; комплект из трёх остальных частей костюма можно оставить надетым.

Фильтр расходуется со временем. Противогаз снижает вдыхание радиоактивной пыли, но не защищает от прямого гамма-излучения и заражённой воды. Для полного костюма с противогазом нужна отдельная схема экипировки: противогаз вместо шлема означает, что проверка полного комплекта из четырёх частей не срабатывает.
